Laser Studio

Logiciel libre de pilotage de laser GRBL, alternative gratuite à LightBurn.

Connexion : Chrome ou Edge requis (API Web Serial). Branchez la machine, cliquez Connecter, choisissez le port série.

G-code : mode laser M4 (puissance dynamique), G21 G90, puissance S calculée d'après $30. Origin en bas-gauche.

Sans machine : utilisez Générer G-code pour exporter un fichier .nc utilisable avec n'importe quel envoi GRBL (Candle, UGS, Pronterface…).
